# study

A calm, keyboard-driven terminal study tracker for exam season: courses, topics, weak spots,
deadlines and study sessions, with a cram timeline that shows whether you're keeping pace.

Work in progress. Install, usage, keybindings and notification setup are documented as each
stage lands.

## Development

```sh
uv venv --python 3.11 .venv
uv pip install -e ".[dev]"
.venv/bin/pytest
```
